EPL_Prologue.1
{
和丽贝卡小小争执了一番之后，我总算说服她出去透透气，陪我走一走。今天正好适合结识一些新朋友；以我们现在并不轻松的处境，这样的机会可不能轻易放过。
}

EPL_Prologue.2
{
我们还在准备时，本地那个又贪财又吝啬的商人加斯顿·科特斯已经碰上了一名新来的女殖民者，还让她见识了一番这里的“待客之道”。他甚至还敢对我出言不逊。
该给他一点教训了。追上去！
}

EPL_Prologue.3
{
加斯顿得到了应有的教训。我该回城里去找那个陌生姑娘。看起来，她似乎也遇上了一些麻烦。
}

EPL_Prologue.4
{
今天早晨发生的事情可真不少。旧大陆来了一艘船，大概是这两个月来的第一艘；我见到了新任司令官，甚至还参加了一场勉强算得上决斗的较量。对手谈不上多可怕，但有那么一瞬间，他的一记突刺确实把我吓了一跳。没想到加斯顿还有这样的身手。希望他没看见我发抖的手，否则那个大嘴巴非得把我这“天不怕地不怕”的名声传得一塌糊涂。
还有那个命运坎坷的姑娘。这倒是个摆脱阿尔卡迪奥那个混蛋遗物的好机会。我得去伊莎贝拉角，把那些东西从岩洞里取回来。
}

EPL_Prologue.5
{
我到了。岩洞藏得很好，路过的人很难偶然找到，不过还是小心为妙。
}

EPL_Prologue.6
{
有人袭击了我们的堡垒。我和丽贝卡躲在城外的岩洞里熬过了袭击，不过还是有两个敌人找到了这里。好在似乎有惊无险。现在战斗声已经停了，我得去看看那里究竟发生了什么。贝琪大概已经跑过去了。
}

EPL_Prologue.7
{
太可怕了。堡垒被毁了，我唯一亲近的人失踪了，而我只能和少数幸存者一起逃走。加斯顿说得对，圣多明各总督是我唯一的希望。可每过一分钟，我都越发觉得自己也许再也见不到贝琪了。过去的生活，到这里就结束了。
}

EPL_Prologue.8
{
我终于踏上了船的甲板。船上有许多失去家园的平民。水手们此刻正在起锚，我们的船也开始移动。出发！
}

EPL_Prologue.9
{
两艘参与洗劫拉维加的海盗船正朝我们直冲过来。和他们交战毫无意义。我们必须尽快甩掉他们，绝不能让平民受到伤害。
}

EPL_Prologue.10
{
我们的船成功甩掉了海盗。是我的错觉，还是他们故意放我们走的？真奇怪。不管怎样，现在我得驶向圣多明各，把发生的一切告诉总督。
}

EPL_Prologue.11
{
已经过去太久了。现在再去圣多明各已经没有意义，海盗多半早就对城市发动了进攻。只能希望西班牙人击退了他们，毕竟圣多明各有高大的城墙和射程很远的火炮。至于我呢？现在我想做什么都可以，只要定下航向就行。前进！
}

EPL_Prologue.12
{
海盗准备从陆路进攻圣多明各。我的妹妹可能就在他们手里。我必须参加这场将在城门外爆发的战斗。
}

EPL_Prologue.13
{
海盗被击败了，但其中没有我的妹妹。我应该去向总督汇报，他现在应该就在自己的官邸里。
}



EPL_TheFirstSteps
{
第一步
}

EPL_TheFirstSteps.1
{
我简直不敢相信发生的一切。原本只能存在于梦中的事情，竟然一瞬间变成了现实。我成了船长。
可我还是害怕。这一切既可怕，又不公平。我的祈祷似乎真的得到了回应，但回应我的并不是天父，而是梅菲斯特。他用自己最擅长的方式实现了我的愿望——最阴险、最卑劣的方式，用我的整个过去，还有贝琪的生命，换来了我的梦想。
不，我还不打算放弃。在前往古巴之前，我必须鼓起勇气回一趟拉维加。如果那些布坎尼尔人真的决定在那里扎下根，我就得和他们的头领谈谈。趁现在，我得想好该以什么样的姿态出现，又该说些什么，才能有机会活着离开那里。
还有这艘双桅帆船。它当然能浮在水上，甚至勉强有资格叫作一艘船，可我是不是应该把拿到的钱花得更聪明一些？
}

EPL_TheFirstSteps.2
{
我就知道，桑德罗·索恩出现在拉维加绝非偶然。他带来的信是给我的。更重要的是，寄信人竟是我的父亲——曼努埃尔·里贝罗·帕尔达尔。我不止一次听说过这位著名私掠船长的名字，却从未想过自己竟是他的女儿……如今在社交场合，我该如何介绍自己呢？@<sEmma> @<sRemedios>船长，还是叫@<sPardal>更好？大概得看我是在和谁说话吧。至于往后的一切，只有时间才能给出答案。
}

EPL_TheFirstSteps.3
{
这是我试图抓住的最后一根稻草，可这个家伙看来真的什么都不知道，否则他早就识破我了。
这个老狐狸。他拼命装作听到那个方圆数百海里都令人畏惧的姓氏时毫不惊讶。我不知道他究竟信了我几分，也不知道他有没有把我的话当真，不过他似乎决定不冒无谓的风险——仿佛我的父亲真的会在意我似的。也好，这倒可以成为我藏在袖子里的一张王牌。
这次去拉维加没有得到我期待的结果，但至少让我学到了一些东西。
}

EPL_TheFirstSteps.4
{
汇报信已经送到，我也得到了问题的答案——一切照旧。现在我不再受任何义务束缚，想做什么都可以，只要定下航向就行。前进！
}



EPL_PZD
{
贵妇的裁缝
}

EPL_PZD.1
{
真是个自以为高贵的贱人，居然觉得我的身份配不上和她交往！我身上的贵族血统可比本地总督夫人还要多。不，我不相信这只是巧合。贝琪亲自设计过那种剪裁的裙子，整个加勒比都不可能再找到第二件一模一样的。
我得冷静下来理清思路。那个女人毫无疑问是西班牙人，也就是说她不是本地人。也许可以打听一下最近有哪些船在这里抛过锚。
}

EPL_PZD.2
{
冷静下来以后，我还是决定不再继续寻找。我想，我只是把愿望当成了现实。那件裙子确实和丽贝卡的很像，但她多半以前在别处见过类似的款式。
}

EPL_PZD.3
{
得到的消息不多。看来我确实应该等太阳落山后去码头走一趟，和当地干活的人聊聊。
}

EPL_PZD.4
{
原来那个女人住在本地总督那里。总督正在举办化装晚会，而且似乎把这种宴会看得比国事还重要，干脆把公务全丢在一边，谁也不见。
无论如何，我都必须在那个傲慢的女人离岛之前混进去。
可上哪里找一套适合这种场合的衣服？如果客人们真的都戴着面具，那倒正好可以利用。
可以去问问本地的放债人或者街头小贩。
}

EPL_PZD.5
{
我进来了。比想象中容易得多。真正困难的是找到那个我只见过一次的女人。更何况她会戴着面具，多半还换了装。我还得设法和她搭上话，再自然地提到她的裁缝。
}

EPL_PZD.6
{
大厅里有两个人正用清亮的声音随意交谈。听起来，两个人都不像我要找的那个女人。
}

EPL_PZD.7
{
这个姑娘太年轻了，多半是总督的女儿之一。肯定不是我要找的人。
}

EPL_PZD.8
{
我很走运地结识了一名西班牙军官，他自称加布里埃尔·德·塞古恩萨。看来他就是“大船赫尔纳尔·迪亚斯号”的船长。他答应替我解决问题，条件是我帮他一个忙：去陪楼下桌边的那个男人坐一会儿。
}

EPL_PZD.9
{
掷骰子时，我甚至没注意到时间已经过去这么久。该从舞台后面的门出去，到码头上去了。加布里埃尔在那里等我。
}

EPL_PZD.10
{
原来那件裙子是索菲娅·德·拉·皮耶达做的——就是布坎尼尔人袭击拉维加前一天，我刚认识的那个姑娘。我本该替她高兴，可我心里只有愤怒。站在索菲娅位置上的，本该是丽贝卡。
