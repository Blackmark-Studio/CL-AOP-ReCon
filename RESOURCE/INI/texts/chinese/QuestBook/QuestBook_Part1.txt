Headhunt.32 {已经领取了范哈伦的赏金。 现在需要稍等片刻， 让蛇人去打探下一个目标的情报。 }
Headhunt.33 {贾.佩斯顿不知怎么找到了我。 我得在他再次出手前先找到他。 我准备去追查他最亲近的同伙——米科.皮斯托莱罗。 他应该就在大陆上的采珠者聚居地附近…… }
Headhunt.34 {我从米科.皮斯托莱罗那里什么都没问出来。 他立刻认出了我， 几乎没多说什么就直接对我发动了攻击， 想要杀了我。 我唯一得知的， 就是贾就在附近…… }
Headhunt.35 {又被贾的打手伏击了。 我得找到他， 彻底解决这个麻烦， 否则永无宁日。 现在回船。 }
Headhunt.36 {真是好运！ 就在北圣胡安湾边， 一艘来自贾的帆船正等着我。 不动用武力他是不会听的。 我可以尝试登船谈谈。 而且这艘船本身也很有意思——也许我该试试把它当作战利品带走？ }
Headhunt.37 {我已经解决了贾.佩斯顿。 现在可以安心回到马提尼克， 去找蛇人领取我的报酬。 }
Headhunt.38 {贾.佩斯顿现在将加入我的船员。 这样的军官远比蛇人承诺的钱财和补给更有价值。 不过， 为了安全起见， 还是暂时别去找蛇人为好…… }
Headhunt.39 {“蛇人”扬信守了承诺——我因为剿灭贾.佩斯顿的帮派， 得到了一套极好的装备和10万比索。 我觉得这份报酬配得上我所做的努力。 }
