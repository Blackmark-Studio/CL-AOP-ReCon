}

}

}
Bucaneer_man_6 {

}

Bucaneer_man_10 {

Myśmy tu, w błocie i sadzy, tylko karmili komary i tłukli dzikie świnie, kiedy wy dokonywaliście wielkich rzeczy. Ale Bóg mi świadkiem, gdy patrzę, jak nasze kobiety znowu śmieją się przy ogniskach... do diabła, Tortuga dziś świętuje! Napij się z nami, kapitanie!
}
