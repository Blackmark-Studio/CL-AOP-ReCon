Bucaneer_man_3 {

}
Bucaneer_man_4 {
La pólvora está húmeda y el mosquete falla cada dos por tres. Tendré que pasarme toda la noche limpiando la cerradura y secando los suministros; de lo contrario, no seré de mucha utilidad si me encuentro con la patrulla española.
}
Bucaneer_man_5 {
Es terriblemente aburrido, capitán. Rastrear jabalíes durante semanas no es para cualquiera. ¿Por casualidad tiene unos cuantos pesos de sobra? Pensaba jugar a los dados con los muchachos, pero no tengo dinero.
}
Bucaneer_man_6 {
Esta selva acabará conmigo algún día. Ayer me mordió algún animal y ahora tengo la mano tan hinchada que me duele al sostener una espada. Los lugareños dicen que se me pasará sola. Espero que no mientan.
}

}
Bucaneer_man_8 {
Ese es tu destino como bucanero. Adiós.

Hemos estado aquí, entre el barro y el hollín, alimentando mosquitos y matando jabalíes mientras usted hacía grandes cosas. Pero Dios sabe, viendo a nuestras mujeres riendo alrededor del fuego otra vez... ¡Caramba, Tortuga se lo está pasando en grande! ¡Tómese una copa con nosotros, Capitán!
}

Pero arrebatar a estas desafortunadas mujeres de las garras del chacal castellano Vargas es una hazaña verdaderamente noble, ¡digna de un rey! ¡Brindemos por tu salud! Hip... ¡diablos, que alguien me dé más ron!
}
Bucaneer_man_12 {

El almirante Le Basque podrá llevarse toda la gloria de Europa, ¡pero aquí solo brindamos por ti! ¡Pásanos una jarra!
